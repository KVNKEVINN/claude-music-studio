⚙️ Required Manual Steps

  • Obtain Claude API Key
    Get your API key from Anthropic Console
    Required: You need a valid Claude API key to use the audio analysis features.
  • Configure Environment Variables
    Add your Claude API key to the configuration file:
    Edit: claude-music-studio\frontend\.env.local Add: VITE_CLAUDE_API_KEY=your_api_key_here
  • Run Automated Setup
    Execute the setup script to install dependencies:
    Double-click: claude-music-studio\setup.bat
  • Test Local Deployment
    Start the development servers:
    Double-click: claude-music-studio\start.bat
    Success: Application should open at http://localhost:3000

🌐 Production Deployment (DigitalOcean)

  • Build Production Version
    Create optimized build for deployment:
    Double-click: claude-music-studio\deploy-production.bat
  • Upload to Server
    Transfer files to your DigitalOcean server (174.138.91.151):
    scp -r deploy/* root@174.138.91.151:/opt/claude-music-studio/
  • Install Docker on Server
    Ensure Docker and Docker Compose are installed:
    ssh root@174.138.91.151 curl -fsSL https://get.docker.com -o get-docker.sh sh get-docker.sh
  • Deploy with Docker Compose
    Start the production services:
    cd /opt/claude-music-studio docker-compose up -d --build
  • Configure Nginx (Optional)
    Set up reverse proxy for custom domain (music-studio.obaisukar.com)
